# UI glossary

- **规划日**：日程、容量与统计共同使用的日期边界。
- **日程树 / 时间轴**：按时间顺序呈现日程条目的主视图；不使用“任务树”。
- **紧凑摘要**：一行展示规划日、条目数、每日容量、已排时间与实际投入的摘要条。
- **独立首次设置页**：首次启动出现的可选设置页面；跳过后立即进入日程页，之后从设置页再次打开。
- **探索原型**：用于比较布局和信息层级的只读设计产物；它记录候选方向，不承担 Android 页面视觉验收。
- **Compose 参考实现**：使用真实 Material 3 主题、组件和设备约束呈现已选方案的 debug 页面；它是日程页视觉验收的依据。
- **视觉真源**：当探索原型与实际页面出现差异时，用来判定颜色、间距、层级和组件表现的唯一参考；当前日程页的视觉真源是 Compose 参考实现。
- **时间轴优先**：日程树是日程页的主画布；摘要负责快速读数，操作入口不与日程条目争夺首屏焦点。
- **竖屏手机优先**：先以当前 Android 竖屏设备确定首屏层级、密度和触控尺寸，再向宽屏扩展布局。
- **单一主操作**：同一首屏只突出一个主要动作；日程页的主要动作是“添加日程”，自由计时和事后补记使用次级层级。
- **摘要信息带**：日程页顶部的一条轻量横向信息带；同一层级显示规划日/项目数、每日容量、已排时间和实际投入，日期切换通过独立入口完成。
- **日期入口**：摘要信息带中的紧凑入口；承载今天、明天、所有日期和任意规划日选择，不把多个日期按钮长期铺在首屏。
- **只读日程节点**：时间轴中的默认条目形态；直接展示时间、标题、计划/实际和状态，完成使用勾选框，其余编辑、计时等动作进入更多菜单。
- **状态驱动显示**：根据当前日程状态决定是否渲染区块；空态只保留说明和添加日程，运行中才插入首行运行卡及暂停/结束控制。
- **暖纸单强调色**：日程页使用暖纸背景、深墨文字与锈红主操作；蓝/绿只保留给低饱和的安排与完成语义。
- **平面时间轴**：时间轴不为每个节点绘制独立大卡，使用细轴、节点和底部分隔线建立层级。
- **紧凑首屏排版**：竖屏首屏使用 22sp 页面标题、16sp 节点标题、12sp 辅助信息和 12–16dp 节点间距；摘要数字不做超大展示。
